# NSX Migration for VCD v1.5.9 (community build based on 1.4.2.2.H001)

Base: Calsoft-Pvt-Ltd/NSX_V2T_Migration_Tool tag MT_v1.4.2.2.H001 (release.yml build 2024-08-02).
Every changed line is marked with a `PATCH-n` comment. Changes per release: v1.5.9-vs-v1.5.8.diff (attached to the GitHub release). Version history: CHANGELOG.md

| PATCH-11 | vcdNSXMigrator.py, core/vcd/vcdOperations.py, rollback.py, vcdNSXMigratorCleanup.py, commonUtils/logConf.py | New `--movecatalog` mode, run after `movevapp`: catalog items stored on the source Org VDC are moved to `<catalog>-v2t` catalogs on the target (created when missing). | PATCH-13 | core/vcd/vcdValidations.py (`dropTier0UplinksWithoutTransport`), core/vcd/vcdConfigureEdgeGatewayServices.py (`configureTargetNAT`) | Only when `TransportSubnets` dropped the edge's transport subnet: uplink subnets recorded as Tier-0 connected (`isT0Connected`) are removed from the non-default uplink list before the NAT rules are built, so their SNAT rules keep the source destination. (3) Services creates the listed routes on the Tier-1, scoped to the network that holds the next hop; a route is recorded as 'creating' before it is created, existing routes for the same destination are completed (next hop, scope, distance), every write is read back, lists are paged; rollback removes only routes it created and keeps the record until their absence is confirmed. | PATCH-15 | core/vcd/vcdValidations.py (`detectUnmanagedVnics`, `validateServiceUplinks`, `normalizeServiceUplinkPlans`, `findExternalNetworkByName`, `nsxvEdgeId`, `nsxvVnic`), core/vcd/vcdOperations.py (`createServiceUplinkNetworks`, `disconnectServiceUplinkVnics`, `attachServiceUplinks`, `configureServiceUplinkNoSnat`, `detachServiceUplinks`, `reconnectServiceUplinkVnics`, `deleteServiceUplinkNetworks`, `updateNATRules`), core/vcd/vcdConfigureEdgeGatewayServices.py (NAT interface mapping), rollback.py, vcdNSXMigrator.py | NSX-V edge vNICs whose portgroup is neither a VCD external network of the edge nor an Org VDC network are detected and logged. With `ServiceUplinks` on the edge: precheck validates transport zone, VLAN, gateway, NSX-V edge id, NSX-V vNIC identity, BGP and names. Names: VCD external network and segment display name = exact portgroup name + `-v2t`; the NSX-T segment id adds a hash of the portgroup id; names longer than 128 characters or a portgroup on two edges stop the precheck; names are compared in code, never placed in filters. Ownership: segments carry tags `v2t-migrator: service-uplink`, `v2t-orgvdc: <source Org VDC uuid>`, `v2t-portgroup: <portgroup id>`, and are reused only with matching VLAN and transport zone; an existing segment or external network that is not the tool's stops the precheck. Topology creates segment and external network (each recorded before creation, recognised after an interruption). Services records the vNIC's original state, disconnects it (identity checked first, result read back), attaches the external network to the Tier-1 only once the vNIC is confirmed disconnected, binds NAT rules that were bound to the vNIC to it, and adds NO_SNAT rules (enabled state, addresses and port profile copied, priority one above the SNAT rule) for the uplink subnet and Tier-1 routes through it to enabled SNAT rules NSX-V bound to another vNIC. Rollback detaches (confirmed), restores the vNIC's original state only after the Tier-1 released the IPs, and deletes only recorded, still-tagged objects, clearing ownership only after deletion or confirmed absence. Records of the earlier record format are converted where unambiguous; otherwise the run stops before any change | Interfaces added through vCenter (MPLS, VPN) are invisible to VCD and were silently dropped by the migration, together with their routes and NAT |
| PATCH-16 | commonUtils/utils.py, commonUtils/threadUtils.py, commonUtils/passwordUtils.py, core/vcd/vcdValidations.py, core/vcd/vcdOperations.py, core/vcd/vcdConfigureEdgeGatewayServices.py, core/nsxt/nsxtOperations.py, core/nsxv/nsxvOperations.py, rollback.py, vcdNSXMigrator.py, vcdNSXMigratorCleanup.py | DHCP and IPsec rollback wait for the NSX-V edge job with a deadline and polling interval and report failure or timeout. Cleanup handles uplink subnets without static pool and no longer modifies the source edge records. Firewall rules linked to NAT rules: the NAT type is read from `type` (SNAT-linked rules get no `appliedTo`), related rules are looked up per rule and a missing one fails, the NAT list is read across all pages; DNAT destination matching is exact and translated ranges/CIDRs are handled. NAT configuration and non-distributed routing continue with the next edge gateway instead of returning. Seven lock sections that could stay locked after a return or exception use `with self.lock`, and the provider VDC lookup releases its lock in `finally`. The worker queue ends on an empty queue without a check-then-get race and acknowledges every job exactly once. NSX-T list calls follow every cursor page. NSX-V certificate private keys are converted through openssl's stdin/stdout and handed over in memory per thread (no key files). The tenant context header is restored on every path of certificate deletion. Metadata values are parsed as literals (`safeLiteral`) instead of `eval`; rollback and cleanup run only their own task expressions.
